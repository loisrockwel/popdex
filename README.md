# PopDex

Un petit jeu de collection : ouvre des CD, découvre des chansons et complète les albums de tes popstars préférées.

- Chaque joueur a sa propre partie, enregistrée dans son navigateur (Profil → Ma sauvegarde pour l'exporter).
- Projet personnel, sans lien avec les artistes, Spotify ni aucune plateforme.

Données : albums et pistes [MusicBrainz](https://musicbrainz.org), listes d'albums studio [Wikipédia](https://fr.wikipedia.org),
streams cumulés agrégés par [Kworb](https://kworb.net), pochettes [Cover Art Archive](https://coverartarchive.org).
Les pochettes et photos appartiennent à leurs auteurs.
